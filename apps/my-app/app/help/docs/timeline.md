## what it does

the semester as a line. each point is a post, positioned by its real date rather
than spaced evenly, so gaps between posts are visible as gaps.

filled points have already happened; hollow ones are still ahead of today. the
selected point turns blue. arriving with no post named selects the most recent one
dated on or before today.

this is the personal devlog. for what actually shipped, read the changelog.

## how to use

1. select any point to load that post — the page does not reload
2. read the title and description on the left, the post body in the card
3. copy the url to share a specific post; `/timeline/<date>` links straight to it
4. use browser back and forward to move through posts you have already opened
