## what it does

the guestbook seen from the other side. every signature ever left on the input
page, each portrait regenerated on the spot from its stored name and drawing kind.

no images are stored anywhere. the page redraws all of them from scratch, which is
why the faces are identical to the ones that were signed.

## how to use

1. scroll the sheet to read the signatures
2. compare a face here against the same name typed into the input page — they will
   match exactly
3. sign the same name twice and nothing happens; a signature is unique per name and
   drawing kind
