## what it does

type a name and the page draws a face from it, live, as a single unbroken svg
path. the same name always produces the same face, because the drawing is derived
from the name rather than from randomness or a network call.

some normalized names produce a feline remix instead, with pointed ears and a cat
muzzle. finding one is the point.

## how to use

1. enter a first and last name and watch the path draw itself
2. change either field to redraw from the new seed
3. download the current drawing as a standalone square svg
4. sign the guestbook to keep it, then see it again on the roll call
