## ahhh my eyes!

the site is no longer legally required to be dark. added a light theme, a system setting, and a little toggle so your eyeballs can choose their own adventure

## all your base are belong to us

got the whole database stack in line with PostgreSQL, Prisma, and Supabase. the schema has real users now, migrations are doing their thing, and the app can finally save something longer than a browser refresh

this was a little over my head at first tbh, but after enough staring at connection strings and generated clients it all started making sense

## the backend has entered the chat

added a whole new Fastify app to the monorepo and wired it into the database. it serves a GraphQL API through Mercurius and TypeGraphQL, with plugins for Prisma, CORS, and the user service

so yeah, the frontend can now ask the backend for actual data instead of yelling into the void

## identify yourself

signup and login are real now

- new accounts get normalized usernames and bcrypt-hashed passwords
- successful signup/login returns a signed JWT
- the frontend talks to GraphQL through generated typed operations
- auth survives a refresh, and signed-in users get their own little dashboard
- wrong username and wrong password return the same vague error because leaking which accounts exist is kinda rude

the `/users/` terminal also got promoted from a bit into an actual interface. `login`, `signup`, `logout`, and `whoami` all work, passwords stay hidden, and the shell prompt changes from `guest@kelev` to your username when you sign in

## sign my weird little yearbook

the name creature generator on `/input/` can now sign its drawings into a guestbook. it saves the normalized name and drawing type instead of an image, then `/input/roll/` rebuilds every creature from the same deterministic seed

added validation, rate limiting, duplicate protection, pagination, and some tests too

very fun
