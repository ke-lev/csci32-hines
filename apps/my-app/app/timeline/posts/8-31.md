## draw me like one of your french girls

my absolute favorite

added a reusable input component and built `/input/`, which turns a first and last name into one continuous SVG face drawn live on the page. the name gets normalized and deterministically turned into the face geometry, so the same name always summons the same creature

i cannot even explain how fun this was, or how rewarding the result is

cat-mode is live!
